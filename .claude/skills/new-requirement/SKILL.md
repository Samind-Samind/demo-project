Skill นี้เป็นทางเข้า (entry point) สำหรับผู้ใช้ในการส่ง requirement ดิบเข้าสู่กระบวนการจัดทำเอกสารของโปรเจกต์ My Coffee Store งานจริงทั้งหมดถูก delegate ไปให้ subagent ชื่อ `requirement-writer`

## ขั้นตอน

1. **หา requirement ดิบ** — ถ้ามี argument ต่อท้ายคำสั่ง (`args`) ให้ใช้ข้อความนั้นเป็น requirement ดิบ ถ้าไม่มี ให้ถามผู้ใช้ตรงๆ ในแชทว่า "ช่วยอธิบาย requirement ที่ต้องการบันทึกหน่อยครับ" แล้วรอคำตอบก่อนไปขั้นถัดไป

2. **เรียก subagent** — เรียกใช้ Agent tool ด้วย `subagent_type: "requirement-writer"` (รันแบบ foreground เพื่อรอผลลัพธ์ก่อนตอบผู้ใช้) โดย prompt ต้องมี:
   - requirement ดิบทั้งหมดที่ได้จากขั้นตอนที่ 1 (ห้ามสรุปย่อจนเสียรายละเอียด)
   - วันที่ปัจจุบัน (ในรูปแบบ YYYY-MM-DD) เผื่อ subagent ใช้กำหนดชื่อไฟล์และไฟล์ log
   - แจ้งให้ subagent ทำตามกระบวนการทั้งหมดที่กำหนดไว้ในคำสั่งของตัวเอง (ตรวจสอบเอกสารเดิม, ถามผู้ใช้เมื่อไม่แน่ใจพร้อมตัวเลือกอย่างน้อย 3 แนวทาง, สร้างเอกสาร spec, อัปเดต backlog, บันทึก log)

3. **รายงานผลกลับผู้ใช้** — เมื่อ subagent ทำงานเสร็จ ให้สรุปให้ผู้ใช้ทราบแบบกระชับ: เอกสารที่สร้าง/แก้ไขทั้งหมด (spec doc, index.md, backlog.md, log) พร้อมลิงก์แบบ markdown ที่คลิกได้

ถ้า subagent ถามคำถามกลับมาระหว่างทาง (ผ่าน AskUserQuestion) ให้ปล่อยให้ผู้ใช้ตอบคำถามนั้นตามปกติ แล้วรอ subagent ทำงานต่อจนจบก่อนสรุปผล

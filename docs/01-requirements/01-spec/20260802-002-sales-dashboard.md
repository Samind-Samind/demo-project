# หน้า Dashboard สรุปยอดขาย (Sales Dashboard)

> สร้างเมื่อ 2026-08-02 จาก requirement ที่ผู้ใช้ระบุ

## ที่มา / บริบท

ผู้ใช้ต้องการให้ร้าน My Coffee Store มีหน้า dashboard สำหรับดูสรุปยอดขาย เพื่อให้เจ้าของร้านและผู้จัดการติดตามผลประกอบการของร้านได้โดยไม่ต้องรวบรวมข้อมูลด้วยมือ ข้อมูลยอดขายที่แสดงจะมาจากออเดอร์ที่เกิดขึ้นในระบบสั่งกาแฟด้วยตนเองจากโต๊ะ (ดู [[20260802-001-table-self-order|Table Self-Order]])

## Feature Requirements

- หน้า dashboard แสดงสรุปยอดขายรวม, จำนวนออเดอร์, และบิลเฉลี่ยต่อออเดอร์
- ผู้ใช้เลือกช่วงเวลาที่ต้องการดูได้เอง (เช่น รายวัน, รายสัปดาห์, รายเดือน หรือกำหนดช่วงวันที่เอง)
- แสดงกราฟยอดขายตามช่วงเวลา (time series) เพื่อดูแนวโน้ม
- แสดงยอดขายแยกตามเมนู/สินค้า เพื่อดูเมนูขายดี-ขายน้อย
- แสดงยอดขายแยกตามโต๊ะ เพื่อดูว่าโต๊ะไหนสร้างยอดขายสูงสุด
- ระบบสิทธิ์การเข้าถึงแบบหลายระดับ (role-based access): เจ้าของร้าน/ผู้จัดการเห็นข้อมูลทั้งหมด ส่วนพนักงานทั่วไปเห็นเฉพาะข้อมูลบางส่วนตามสิทธิ์ที่กำหนด
- ผู้ใช้ที่มีสิทธิ์เพียงพอสามารถ export/พิมพ์สรุปยอดขายที่ดูอยู่เป็นไฟล์ PDF ได้

## User Stories / Use Cases

- ในฐานะเจ้าของร้าน ฉันต้องการดูสรุปยอดขายรวมของร้านในแต่ละช่วงเวลาที่เลือกเอง เพื่อประเมินผลประกอบการ
- ในฐานะเจ้าของร้าน ฉันต้องการรู้ว่าเมนูไหนขายดีที่สุด เพื่อวางแผนสต๊อกและโปรโมชัน
- ในฐานะผู้จัดการ ฉันต้องการ export รายงานยอดขายเป็น PDF เพื่อส่งต่อให้เจ้าของร้านหรือเก็บเป็นหลักฐาน
- ในฐานะพนักงานทั่วไป ฉันต้องการเห็นข้อมูลยอดขายเฉพาะส่วนที่เกี่ยวข้องกับงานของฉัน โดยไม่เห็นข้อมูลที่ละเอียดอ่อนของร้าน

## Business Rules

- สิทธิ์การเข้าถึงข้อมูลใน dashboard แบ่งตาม role อย่างน้อย 2 ระดับ: เจ้าของร้าน/ผู้จัดการ (เห็นทั้งหมด) และพนักงานทั่วไป (เห็นแบบจำกัด) — รายละเอียดขอบเขตของแต่ละ role ให้กำหนดในเอกสารออกแบบเชิงเทคนิคต่อไป
- ข้อมูลยอดขายที่แสดงต้องคำนวณจากออเดอร์ที่เกิดขึ้นจริงในระบบสั่งอาหาร ([[20260802-001-table-self-order|Table Self-Order]]) เท่านั้น
- ช่วงเวลาที่เลือกดูข้อมูลต้องยืดหยุ่น ไม่ผูกตายตัวกับช่วงใดช่วงหนึ่ง

## ขอบเขต (Scope)

### สิ่งที่ทำ (In Scope)
- หน้า dashboard สรุปยอดขายรวม, ตามช่วงเวลา, ตามเมนู, ตามโต๊ะ
- การเลือกช่วงเวลาเองได้ (วัน/สัปดาห์/เดือน/กำหนดเอง)
- สิทธิ์การเข้าถึงข้อมูลแบบหลายระดับ (role-based access)
- Export/พิมพ์รายงานเป็น PDF

### สิ่งที่ไม่ทำ (Out of Scope)
- การพยากรณ์ยอดขาย (sales forecasting) หรือการวิเคราะห์เชิงลึกด้วย AI
- การ export เป็นรูปแบบไฟล์อื่นนอกจาก PDF (เช่น Excel/CSV) ในเวอร์ชันนี้
- การจัดการ/แก้ไของค์ประกอบสิทธิ์ผู้ใช้ (user & role management) ซึ่งถือเป็น requirement แยกต่างหาก

# ระบบสั่งกาแฟด้วยตนเองจากโต๊ะ (Table Self-Order)

> สร้างเมื่อ 2026-08-02 จาก requirement ที่ผู้ใช้ระบุ

## ที่มา / บริบท

ผู้ใช้ต้องการให้ร้าน My Coffee Store มีระบบที่ลูกค้าสามารถสั่งเครื่องดื่ม/อาหารได้เองจากที่โต๊ะ โดยไม่ต้องเดินไปสั่งที่เคาน์เตอร์ เพื่อลดภาระพนักงานและเพิ่มความสะดวกให้ลูกค้าที่นั่งในร้าน

## Feature Requirements

- ลูกค้าสแกน QR code ที่ติดอยู่บนโต๊ะ เพื่อเปิดหน้าสั่งอาหาร/เครื่องดื่มของโต๊ะนั้นโดยเฉพาะ (ไม่ต้องติดตั้งแอป ไม่ต้อง login)
- หน้าสั่งอาหารแสดงเมนูทั้งหมดของร้าน พร้อมราคา และให้ลูกค้าเลือกจำนวน/ตัวเลือกเสริม (เช่น ระดับความหวาน, ชนิดนม) ก่อนยืนยันออเดอร์
- ระบบต้องผูกออเดอร์แต่ละรายการเข้ากับหมายเลขโต๊ะที่สแกน เพื่อให้พนักงานทราบว่าออเดอร์มาจากโต๊ะไหน
- ลูกค้าสามารถสั่งเพิ่มได้หลายรอบจากหน้าเดิม (session เดียวกัน) โดยไม่ต้องสแกน QR ใหม่ทุกครั้ง ตราบใดที่ยังนั่งอยู่ที่โต๊ะ
- เมื่อออเดอร์เสร็จ (พนักงาน/บาริสต้าทำเสร็จ) ระบบต้องแจ้งเตือนในหน้าสั่งของลูกค้าโดยตรง ว่าออเดอร์ไหนพร้อมเสิร์ฟแล้ว
- พนักงานต้องเห็นสถานะออเดอร์ของแต่ละโต๊ะ (รอทำ/กำลังทำ/เสร็จแล้ว) เพื่ออัปเดตสถานะและให้ระบบแจ้งลูกค้าได้ถูกต้อง
- ลูกค้าชำระเงินตอนพนักงานนำมาเสิร์ฟ หรือเก็บรวมเป็นบิลท้ายสุดตอนจะกลับ (ไม่ใช่การจ่ายเงินผ่านระบบตอนสั่ง) — ระบบจึงต้องสะสมรายการที่สั่งทั้งหมดของโต๊ะไว้เป็นบิลเดียวเพื่อให้พนักงานเก็บเงินท้ายบิลได้ถูกต้อง

## User Stories / Use Cases

- ในฐานะลูกค้าที่นั่งในร้าน ฉันต้องการสแกน QR code ที่โต๊ะเพื่อดูเมนูและสั่งเครื่องดื่มได้เองโดยไม่ต้องเรียกพนักงาน
- ในฐานะลูกค้า ฉันต้องการรู้ว่าออเดอร์ของฉันพร้อมเสิร์ฟแล้วหรือยัง โดยไม่ต้องเดินไปถามที่เคาน์เตอร์
- ในฐานะพนักงาน/บาริสต้า ฉันต้องการเห็นออเดอร์ที่เข้ามาพร้อมหมายเลขโต๊ะ เพื่อทำเครื่องดื่มและอัปเดตสถานะให้ลูกค้าทราบ
- ในฐานะพนักงานเก็บเงิน ฉันต้องการดูสรุปรายการที่แต่ละโต๊ะสั่งทั้งหมด เพื่อคิดบิลตอนลูกค้าจะกลับ

## Business Rules

- 1 QR code ผูกกับ 1 หมายเลขโต๊ะเท่านั้น (ห้ามสั่งข้ามโต๊ะผ่าน QR ของโต๊ะอื่น)
- ออเดอร์ทั้งหมดที่สั่งจากโต๊ะเดียวกันในช่วงเวลาที่นั่งอยู่ ถือเป็นบิลเดียวกัน จนกว่าพนักงานจะปิดบิล/เคลียร์โต๊ะ
- ลูกค้าไม่ต้องชำระเงินผ่านระบบตอนกดสั่ง — การชำระเงินเกิดขึ้นที่หน้าร้าน/เคาน์เตอร์เท่านั้น (ระบบสั่งอาหารกับระบบชำระเงินแยกจากกันในเวอร์ชันนี้)
- ต้องแจ้งสถานะออเดอร์ให้ลูกค้าทราบผ่านหน้าสั่งอาหารเดิม (ไม่ใช่ผ่านช่องทางอื่น เช่น SMS หรือแอปแยก)

## ขอบเขต (Scope)

### สิ่งที่ทำ (In Scope)
- การสั่งอาหาร/เครื่องดื่มด้วยตนเองผ่าน QR code สำหรับลูกค้าที่นั่งในร้าน (dine-in) เท่านั้น
- การแจ้งสถานะออเดอร์แบบ real-time ในหน้าสั่งของลูกค้า
- หน้าจัดการออเดอร์และสถานะฝั่งพนักงาน/บาริสต้า

### สิ่งที่ไม่ทำ (Out of Scope)
- การสั่งแบบ takeaway หรือ delivery (นอกร้าน)
- การชำระเงินผ่านระบบออนไลน์/ในแอป (ชำระที่เคาน์เตอร์เท่านั้นในเวอร์ชันนี้)
- ระบบสมาชิก/บัญชีผู้ใช้สำหรับลูกค้า (ไม่ต้อง login)
